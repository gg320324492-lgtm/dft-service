## 项目目标与阶段
用 DFT 解释"臭氧微纳米气泡+UV"处理养殖水体协同机制。第 1 阶段（水相基线）收尾未完；第 2 阶段气相 NH₃+O₃（C1 铵氮）机理进行中。

- 一律用 **WSL2 Ubuntu 24.04.4**：PySCF 2.14.0（venv `~/dftvenv`，Python 3.12.3）。宿主 Windows 无量子化学软件、无 MSVC。

## PySCF 坑（已验证）
1. libxc `wb97xd` 不含 −D2，须显式补 Chai–Head-Gordon D2（Kr₂/Ne₂ 探针验证）。
2. 内置 thermo() 单位 bug 42.7×；Hessian 对称化轴 `transpose(1,0,3,2)`。
3. SMD 梯度用 `mf.nuc_grad_method().kernel()`；`mf.stability(internal=True, external=False, return_status=True)` 返回**四元组 `(mo_i, mo_e, stable_i, stable_e)`**（052/058 两次实测，装机的顺序如此；058 曾误拆 3 项中断）。稳定性 verbose 日志必须**直接写文件句柄**（StringIO+finally 会丢），返回状态/原始 repr 先落盘再汇总。
4. PySCF `harmonic_analysis` 虚频是复数，`float()` 丢虚部得假 0.0；交叉核对用 `imaginary_freq=False`+显式 `mass=`。
5. 频率换算两路线（SI 独立推导）：amu 系数 5140.4871 / 电子质量 219474.6314（比=√1822.888=42.695）。
6. SMD 解析 Hessian 接线不一致（ISWIG 缺口）=平台侧，修复须另行立项（017）。
