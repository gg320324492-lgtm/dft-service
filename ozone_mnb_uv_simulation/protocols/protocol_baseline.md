# 基线计算协议：H₂O / O₃ / O₂

本文件固定第 1 阶段基线批次的计算设置，后续所有反应计算都以本批结果为参照。
本批只建立参照，不涉及反应路径、过渡态、离子效应或界面模型。

## 1. 统一的模型化学

| 项目 | 设置 |
| --- | --- |
| 泛函 | ωB97X-D |
| 基组 | def2-TZVP |
| 积分网格 | PySCF `grids.level = 5`（Lebedev/Treutler；H₂O 约 90 064 点，属细网格） |
| SCF 收敛 | `conv_tol = 1e-11`，`max_cycle = 200` |
| 几何优化 | pyberny（`pyscf.geomopt.berny_solver`），阈值：梯度最大 2×10⁻⁵、梯度 RMS 1×10⁻⁵、步长最大 1×10⁻⁴、步长 RMS 6×10⁻⁵（Hartree/Bohr、Bohr、rad） |
| 频率 | 解析 Hessian，对称化后做质量加权正交分析，并投影掉平动/转动 |
| 气相 | 无溶剂 |
| 水相 | SMD(H₂O)，PySCF 内置 Minnesota 溶剂库（180 种溶剂）中的 `water` |
| 热化学 | 刚性转子 + 谐振子 + 理想气体，298.15 K、101325 Pa（1 atm） |

## 3. ωB97X-D 在本后端中的实现方式（重要）

PySCF 的 `xc = 'wb97xd'` 调用 libxc 的 `XC_HYB_GGA_XC_wB97X_D`，该条目**只包含泛函的 DFT 部分，不含经验 −D2 色散项**。这一点经过数值验证：
以 Kr₂ 为探针，`E(wb97xd) − E(wb97x)` 在 R = 6、8、12、20 Å 处分别为 −45.1970、−45.1979、−45.1953、−45.1975 kcal/mol，差值不随距离变化，没有 R⁻⁶ 尾巴（Ne₂ 探针给出同样结论）。因此本批**显式补加** Chai–Head-Gordon 的 −D2 色散项：

$$E_\mathrm{disp} = -s_6 \sum_{A<B} \frac{C_6^{AB}}{R_{AB}^6}\, f_\mathrm{damp}(R_{AB}),\qquad
f_\mathrm{damp}(R) = \frac{1}{1 + a\,(R_0^{AB}/R)^{12}}$$

- $s_6 = 1.0$，$s_{R6} = 1.1$（$R_0^{AB} = 1.1\,(R^\mathrm{vdW}_A + R^\mathrm{vdW}_B)$），$a = 6.0$，指数 12
- $C_6^{AB} = \sqrt{C_6^A C_6^B}$，原子 $C_6$ 与范德华半径取 Grimme(2006) D2 表
- 这些参数在三处独立来源中一致：Q-Chem 手册（`DFT_D = EMPIRICAL_CHG`，`DFT_D_A` 默认 600 → a = 6.0；ωB97X-D 自动启用 DFT-CHG）、Gaussian 手册（wB97XD 的 S6 = 1.0、SR6 = 1.1、D6 = 6.0、IA6 = 12）、以及原始文献 Chai & Head-Gordon, *PCCP* **10**, 6615 (2008) 式 (3)。

**泛函参数核对**（PySCF `libxc.rsh_coeff` 采用 `α + β·erfc(ωr)` 约定）：

| 泛函 | ω (bohr⁻¹) | 短程 HF 交换 | 长程 HF 交换 | 文献值 |
| --- | --- | --- | --- | --- |
| wB97X-D | 0.2 | 1 − 0.777964 = 22.20 % | 100 % | 22.2 % / 100 % / ω = 0.2 |
| wB97X | 0.3 | 1 − 0.842294 = 15.77 % | 100 % | 15.77 % / 100 % / ω = 0.3 |

对 H₂O、O₃、O₂ 这三个小分子，−D2 项在成键距离上被阻尼函数压制，数值为 10⁻⁷–10⁻⁶ Hartree（见结果表），对几何和频率的影响远小于收敛阈值。该项仍逐条列出，不做隐藏。

## 4. 溶剂模型：SMD(H₂O)

PySCF 的 SMD 采用 Minnesota 溶剂描述符数据库，`water` 条目为：

| 描述符 | 值 |
| --- | --- |
| n（折射率） | 1.3328 |
| n₂₅ | 1.3323 |
| α（氢键给体） | 0.82 |
| β（氢键受体） | 0.35 |
| γ（表面张力项） | −1.0（水不使用） |
| ε（介电常数） | 78.355 |
| φ / ψ | −1.0（水不使用） |

SMD 的静电部分在 SCF 中自洽求解；梯度为解析式。Hessian 的静电部分为解析式，空穴/色散/溶剂结构（CDS）部分由 PySCF 用解析梯度的有限差分得到（步长 1×10⁻⁴ Bohr）。因此**本后端直接支持 SMD(H₂O)，无需退化为其他连续介质模型**。

## 5. 热化学：不使用 PySCF 内置 `thermo()`

`pyscf.hessian.thermo.thermo()` 存在单位错误：它把频率→振动温度的换算写成
`au2hz = (HARTREE2J / (ATOMIC_MASS · BOHR²))^½ / 2π`，其中用的是**原子质量单位**而非电子质量，
得到的换算系数为 7396 K/Hartree，而正确值应为 `HARTREE2J/k_B = 3.1577×10⁵` K/Hartree，**偏小 42.7 倍**。
实测：输入正确的 H₂O 频率（1619.57 / 3875.80 / 3985.09 cm⁻¹）时，该函数的 ZPE 为 5.06×10⁻⁴ Hartree，
而正确的 ZPE 为 0.021598 Hartree。

因此本批的热化学由 `run_baseline.py` 自行实现（刚性转子 + 谐振子 + 理想气体，SI 单位），
并以 NIST 气相标准熵 S°(298.15 K) 作为外部标定（见结果汇总）。

## 7. 验收标准

每个体系/相态均须满足：

1. SCF 收敛（`mf.converged = True`，能量收敛限 1×10⁻¹¹）；
2. 优化收敛：最终 Cartesian 梯度最大分量 < 5×10⁻⁵ Hartree/Bohr；
3. 是极小值：虚频数 = 0；
4. Hessian 对称性：|H − Hᵀ| < 1×10⁻⁴（正确的原子/坐标转置为 `transpose(1,0,3,2)`）；
5. 振动模式数 = 3N − 6（线性分子 3N − 5）；
6. O₂ 三重态的自旋污染可控（报告 ⟨S²⟩）；
7. 气相计算得到的标准熵与 NIST 实验值 S° 相符（标定热化学实现）。

## 8. 已知的方法层面偏差（非错误）

- ωB97X 优化/频率 + D2 单点校正得到的 ∠HOH = 105.4°，高于实验平衡值 104.5°。这是泛函本身的系统偏差，不是实现问题：换用 aug-cc-pVTZ（105.08°）和 def2-QZVP（105.14°）结果一致，而 MP2/def2-TZVP 给出 104.63°。
- **O₃ 的 O–O 键长偏短、伸缩频率偏高是泛函层级的系统偏差。** ωB97X 优化/频率 + D2 单点校正得到 r(O–O) ≈ 1.238 Å（实验 1.2717 Å，偏短约 0.034 Å），对称伸缩频率偏高约 200 cm⁻¹。为评估偏差来源，额外做了固定键角 118.13° 的键长扫描（见 `results/00_baseline/o3_ccsdt_scan.txt`）：抛物线拟合极小点 ωB97X（工作流 DFT 部分）= **1.2393 Å**、CCSD = 1.2483 Å、CCSD(T) = **1.2731 Å**（实验 1.2717 Å）。**CCSD(T) 极小点与实验几乎重合，而 ωB97X 仍系统性偏短**。该参考扫描支持此偏差是当前泛函层级的系统偏差，且未发现所审计实现导致该偏差的证据；须注意固定角度的一维扫描不足以构成对根因的完全证明。涉及 O₃ 的反应能垒须做方法敏感性检验，不能把该泛函下的 O₃ 几何/频率直接外推为定量预测。
- 谐振子近似下 OH 伸缩频率相对实验谐振值偏高约 +40 cm⁻¹，弯曲偏低约 −30 cm⁻¹，属该级别方法的常规表现；本批结果均为**未缩放**的谐振频率。
- SMD 是隐式溶剂，不含显式氢键、界面电场和局部浓度效应；本批的水相结果应理解为"本体水的连续介质参照"，后续界面模型会在此基础上叠加。
