## 2. 各候选论证

### C1 铵态氮（NH₃/NH₄⁺）的臭氧/UV 协同氧化【优先讨论对象】

1. **对象与养殖相关性**：总氨氮（TAN = NH₃+NH₄⁺）是循环水/工厂化养殖最核心的水质负荷（鱼排泄与饵料降解）；氨氮毒性以分子态 NH₃ 为主、**与鱼种/发育阶段/pH/温度相关（具体阈值待实验体系确定，不采用通用数字）**。S1 专文讨论 RAS 中臭氧除氨的"潜力与局限"，并指出机理理解存在空白（S1 原文）；**S1 摘要补充**：海水中氨氧化为 Br⁻ 催化、终产物 N₂、pH 无关，但需 OPO 先积累至毒性量——作者判定"对动物健康有风险且经济上不可行"（021 核实）。
2. **拟解释的实验现象**：为何臭氧对 TAN 的直接去除慢且强 pH 依赖（S1/S3），而 UV/O₃ 协同显著加快（S2）；海水/咸水体系中溴系中间体是否改变路径（S1）。
3. **拟研究的分子反应**（区别于宏观动力学）：水相中 ·OH + NH₃ → NH₂· + H₂O（抽氢）及其后续 O₂ 加成引发的 NO₂⁻/NO₃⁻ 链条；O₃ + NH₃ 直接反应缓慢的电子结构原因（N 孤对质子化/前线轨道）；NH₃/NH₄⁺ 形态对能垒的影响（pH 效应的分子根源）。
4. **DFT 能回答（021 批收窄）**：**水相**基元步骤的反应自由能、能垒与形态（NH₃/NH₄⁺）效应；·OH 抽氢 vs O₃ 加成的竞争。**已有气相计算（S13，2013）**：NH₃+O₃ 无垒加合物 → 六通道（P1–P6），P1(2)/P4 最可能——本项目水相工作以此为**通道基准**；本项目新增 = SMD 水相环境、溶剂效应、NH₄⁺ 对照与 ·OH 通道（S13 未涉及）。
5. **需其他方法/实验**：宏观速率常数与产物分布（已有 S2 实验值可对标）；链式机理的完整动力学建模（类似 S5 的 kinetic model 方法）；气液传质（不属 DFT）。
6. **与主题的联系**：直接对应"臭氧+紫外协同"（S2 的 O₃/·OH 贡献分解）；不依赖界面（微纳米气泡作为提高 O₃ 溶解的工程背景，见 S4 报告的接触器章节）。
7. **所需实验输入**：体系是淡水/海水/咸淡水（决定是否引入 Br⁻ 途径，S1）；pH 与温度；TAN 初始浓度与测定方法。
8. **难点与初步工作量**：开壳层（·OH/NH₂·）水相计算需与既有 SMD 路径组合（方法环节须重新验证——见任务草案）；首批建议 2–3 个基元步的反应能+过渡态（水相优化受阻时以"气相+水相单点校正"受限流程替代，方法边界明示）。初步工作量：每基元步 ~10–15 次求值量级。
9. **文献出处（021 批修订）**：S1、S2、S3、S4、**S13（气相机理计算，2013；依据仅摘要）**。**研究定位修正**：不再是"无计算文献的空白"，而是"**有气相机理计算（S13）、缺水相扩展与形态/溶剂效应研究**"。

### C2 氯离子 → 活性氯物种与含氧副产物

1. **对象与相关性**：Cl⁻ 是海水/咸淡水养殖主要阴离子；O₃/UV 处理生成 ClO₃⁻（主）与 ClO₄⁻（副）等副产物，养殖水体排放与生物毒性关注点（S5）。
2. **拟解释现象**：臭氧化含 Cl⁻ 水体中氯酸盐生成速率与 pH 依赖（S5，pH 5.5–12）；UV(254)/O₃ 联合对 Cl⁻ 氧化的增强**（S6 为 pH 0–2 强酸条件——与养殖水体差异大，仅作机理参考；021 限定）**。
3. **拟研究分子反应**：Cl⁻+O₃→ClO⁻+O₂；·OH+Cl⁻→Cl₂·⁻；Cl₂·⁻+O₃→ClO·；ClO/ClO₂· 复合与水解生成 ClO₃⁻/ClO₄⁻ 的关键步骤（S5/S6 机理）。
4. **DFT 能回答**：Cl₂·⁻/ClO·/ClO₂· 等自由基步骤的生成能与能垒；哪些步骤控制副产物分支。
5. **需其他方法**：完整动力学模型（S5 已建——DFT 价值在于复核其中缺速率常数的步骤）；自由基浓度的直接测量（EPR）。
6. **主题联系**：★（S6 直接是 UV+O₃ 体系）。
7. **所需实验输入**：Cl⁻/Br⁻ 浓度（水体类型）、pH。
8. **难点与工作量**：阴离子自由基与水相电子密度的稳定性描述（SMD 对阴离子自由基的适用性须先验证）；工作量中等。
9. **出处**：S5、S6。
- **不推荐首选的原因**：机理的宏观动力学已有完整模型（S5），DFT 增量价值相对小；且阴离子自由基水相计算是当前水相数值问题的直接风险面。

### C3 病毒分子损伤：鸟嘌呤/敏感氨基酸的初始氧化【备选】

1. **对象与相关性**：鱼类病毒病是养殖重大损失来源（S10–S12：IHNV、BFNNV 等）；水处理灭活的分子机理核心 = 病毒组分的氧化损伤。
2. **拟解释现象**：为何同一氧化剂对不同病毒灭活机制不同（S8：组成/结构/功能）；臭氧源 ·OH 对基因组损伤远超 O₃ 分子（S9）。
3. **拟研究分子反应**（**分子损伤位点**层面，不代表完整病毒灭活）：·OH/O₃/¹O₂ 对**鸟嘌呤碱基**（最易氧化；S8 实验先例：TMV RNA 鸟嘌呤优先损伤——**替代病毒证据**）的加成/抽氢初始步；对衣壳敏感氨基酸（W/Y/H/M/C，S7——亦为替代病毒证据）。**【021 批明确】**鱼类病毒方向现有文献仅有敏感性/应用数据（S10/S11/S12），无分子损伤机制研究；替代病毒先例不得直接作为鱼类病毒灭活机制证明。
4. **DFT 能回答**：各损伤位点的氧化自由能与能垒排序（S9 已有 DFT 先例）；·OH 与 O₃ 的位点选择性差异。
5. **需其他方法/实验**：病毒增殖与感染性测定（蚀斑/基因拷贝）；QM/MM 或晶体结构（全病毒尺度不可 DFT）；完整病毒灭活效果只能来自实验。
6. **主题联系**：O₃ 与 ·OH 双通道（臭氧+紫外协同的下游）；界面不进入首批。
7. **所需实验输入（缺项，明列）**：**具体病毒名称未确定**（不得自行指定）；该病毒的衣壳/基因组结构数据；灭活实验数据（剂量-响应）；是否海水体系（BFNNV 对臭氧低敏感 vs IHNV 敏感——S10，病毒选择直接改变可行性）。
8. **难点与工作量**：水相开壳层计算；鸟嘌呤水合互变；若做衣壳需 QM/MM（成本高）。首批可先做鸟嘌呤 + 2–3 个氨基酸的小模型（工作量中等）。
9. **出处**：S7、S8、S9、S10、S11、S12。

## 3. 推荐结论（方案建议，非选定）

- **优先讨论对象：C1（铵态氮的臭氧/UV 协同氧化）**——养殖相关性最强（TAN 核心指标 + 文献明确机理空白）、模型最小且直接复用第一阶段 O₃/H₂O/O₂ 基线、有可对标实验速率常数（S2）、成本最低。
- **备选：C3（病毒基因组鸟嘌呤初始氧化）**——覆盖病毒方向、有 DFT 先例（S9）、鸟嘌呤小模型可先行；但需先补齐病毒与结构缺项。
- C2 记录在案（海水体系若被确认，其优先级将上升——Cl⁻/Br⁻ 化学在海水 O₃ 化学中占主导，S1/S4）。
