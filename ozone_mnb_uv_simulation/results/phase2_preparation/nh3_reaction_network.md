# 氨氮氧化分支反应网络（带来源与证据等级 · JOB-2026-0906-023）

**证据等级**：L1 = 原文直接支持的基元反应（计算或实验原数据）；L2 = 宏观实验观察或拟合模型；L3 = 跨文献拼接假设；L4 = 本项目拟验证的问题。
**总原则**：不预设 NH₃ 必然依次经 NH₂·、NH₂OH、NO₂⁻ 到 NO₃⁻；酸碱平衡（NH₃+H⁺⇌NH₄⁺，pKa≈9.25@25 °C，标准常识）**不是氧化反应**，与氧化链分开处理；**OH⁻（氢氧根离子，O₃ 分解引发剂）与 ·OH（羟基自由基，氧化剂）严格区分**。

## 1. O₃ 直接反应通道（气相机理，S13 全文 = L1）

```
NH₃ + O₃ ──(无垒)──> C1(OOON 四员环) ──TS1──> IN1
                       └─(无垒)─> C2(OOOHNH 六员环)
IN1 ──TS2──> CP1 ──(无垒)──> P1: HOO· + H₂NO·        [L1, S13 印刷 p.272–273]
IN1 ──TS8──> CP3 ──(无垒)──> P4: HNO + H₂O₂          [L1]
CP3 ──TS3──> IN2 ──TS4──> IN3 ──TS5──> CP1           [L1]
CP3 ──TS9──> CP4 ──(无垒)──> P5: H₂O + HNO₂          [L1]
CP3 ──TS10──> CP5 ──(无垒)──> P6: NO + HO₂· + H₂     [L1]
C2  ──TS7──> P2: OH· + H₂NO₂·                        [L1]
C2  ──TS6──> P3: O₂ + H₃NO                           [L1]
```
- 能垒（CCSD(T)）与相对能量见 `S13_2013_extraction_record.md` §5–6；**电子态警示**：P1/P2 双自由基片段、P3 含 O₂(³Σg⁻)、P6 三片段、TS6 T1=0.1048。
- 限制：**全部气相**（Gaussian 03，B3LYP+CCSD(T)/G3B3）；水相版本 = 本项目 L4。

## 4. 用户反应链线索逐环节判定

用户线索：**NH₃ → NH₂ → NH₂OH → NO₂⁻ → NO₃⁻**
| 环节 | 判定 |
|---|---|
| NH₃ → NH₂· | ·OH 抽氢：宏观速率有（L2-S2）、气相 PES 有理论先例（L3/L1 域）；**水相基元步 = L4 本项目拟验证** |
| NH₂· → NH₂OH | 经 O₂/HO₂ 的氧加成路径：**L3 拼接假设**（aminoperoxyl 文献支持 NH₂OO· 形成，但其到 NH₂OH 的转化需核验）；酸碱平衡不产生 NH₂OH |
| NH₂OH → NO₂⁻/NO₃⁻ | **L3 拼接假设**（NH₂OH+O₃ 文献是外加试剂体系 S0304389419304030；作为 NH₃ 氧化中间体的证据缺） |
| NO₂⁻ → NO₃⁻ | **L2**（快，证据充分）；与 NH₃ 氧化的衔接仍为假设 |
| 竞争/其他氮去向 | N₂（海水 Br⁻ 断点，L2-S1）、NH₄⁺ 颗粒（NH₄NO₃，L2-Olszyna）、HNO₂/HNO₃（S13 气相 P5）——保留 |

## 5. 卤素参与路径（单列）

- **Br⁻（海水）**：O₃→HOBr/OBr⁻→NH₂Br(k=40 M⁻¹s⁻¹)→NHBr₂/NBr₃ 断点→N₂（L2，S1）；OPO 毒性。**依赖水体类型确认**。
- **Cl⁻**：O₃–Cl⁻ 体系（L2，S5：ClO⁻ 引发→ClO₂·/ClO·→ClO₃⁻）；254 nm UV 光化学（S6，pH 0–2，仅机理参考）。
- 与 NH₃ 的耦合：HOBr+NH₃→NH₂Br（L2，S1）——**咸淡水体系中氧化剂被卤素分流**，是模型范围决策点。
