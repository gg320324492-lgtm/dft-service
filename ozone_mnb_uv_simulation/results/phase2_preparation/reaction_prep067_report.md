## 1. 两个优先通道的文献登记（S13, Asgharzade & Vahedpour 2013, PRK 38(3):266-282）
### 通道P4：NH₃ + O₃ → HNO + H₂O₂（闭壳层 singlet 产物）
- 路径：R → C1 → TS1 → IN1 → TS8 → CP3 → **P4**（CP3=HNO···H₂O₂复合物，5O–3H长键）。
- 能量：**P4低于R 32.64 kcal/mol（CCSD(T)）**；表值ΔE_CCSD(T)=−33.23/−32.64（B3LYP/CCSD(T)）；热化学表：ΔH₀=−33.09（实验−31.9）、**ΔG₀=−34.33（实验−33.45，论文自评相对误差−2.6%）**、TΔS=+9.22 kcal/mol。
- 能垒：TS1（C1→IN1）**29.68 kcal/mol CCSD(T)**；TS8（IN1→CP3）正文51.08、表推51.80（=41.80−(−10.00)）——**文献内部不一致已登记**；CP3→P4无垒（5O–3H断键直接分解）。
- T1：R=**0.0346**（>0.02闭壳层阈值→**O₃反应物区多参考风险**）；TS1=0.0452（接近开壳层0.045上限）；TS8=0.0215；CP3=0.0145；P4=0.0284。

### 通道P1(2)：NH₃ + O₃ → HOO· + H₂NO·（双自由基产物）
- 路径：R → C1 → TS1 → IN1 → TS2 → CP1 → **P1**（CP1=HOO···H₂NO₂？不——CP1=HOO···H₂NO复合物，1N–7O长键）。
- 能垒：TS2（IN1→CP1，5O–6O断+1N–7O成）**30.77 kcal/mol CCSD(T)**；**CP1→P1无垒**（1N–7O断键直接分解）。
- 能量：P1低于R 5.82 kcal/mol（B3LYP）；热化学表：ΔE_CCSD(T)=−19.40、ΔH₀=−19.20、**ΔG₀=−21.35**、TΔS=+6.18 kcal/mol。
- T1：TS2=**0.0507**（超过开壳层0.045上限→明显多参考）；CP1=0.0212；P1=0.0201。
