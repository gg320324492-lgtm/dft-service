## 2. 阶段 B：SMD 实际路径验证（通过）

### 2.1 只读核对（记录实际实现，不凭气相推定）

PySCF 2.14.0，`pyscf.solvent.smd`：
- **能量**：`e_tot = E_DFT + e_solvent（静电，PCM 机制）+ e_cds（CDS）`；`scf_summary` 分别记录 `e_solvent` 与 `e_cds`（`_attach_solvent.py` L113–129）。
- **梯度**：`with_solvent.grad(dm) = grad_qv + grad_solver + grad_nuc + de_cds`（`smd.py` L516–526）；前三项为解析 PCM/SMD 项。
- **CDS 项实现**：`libsolvent` C 例程 `mnsol_interface_` **同时返回 CDS 能量与梯度**（`get_cds_legacy`）——解析，**无有限差分项**（已核实 smd.py 梯度路径无 fdiff 调用）。

## 4. 结果解释边界

- 本批水相结果**只称"未收敛的水相弛豫几何"**——两候选均未达 max|g|≤1e-5，**不能称"SMD 水相已收敛驻点候选"**。
- 显式单水 + SMD 连续介质只是当前水合模型，不代表完整液态水、微纳米气泡界面或 UV 激发反应。
- 气相→水相总能量差**不是结合自由能**；不据此宣称臭氧稳定性、反应速率或处理效果变化。
- 本批未计算水相 Hessian、热化学、CP 结合能、CCSD(T)、激发态、离子或反应路径。
