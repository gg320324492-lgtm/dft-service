# 臭氧微纳米气泡—紫外协同模拟工作区

本目录用于保存“臭氧微纳米气泡与紫外协同处理养殖水体”的**分子尺度模拟**。它以预实验方案中的处理方式（对照、臭氧、紫外、臭氧+紫外）和变量（处理时间、臭氧强度、紫外功率、循环流量、水体基质）为问题来源，为实验结果提供可检验的机理解释和后续模拟数据。

## 本工作区回答什么问题

| 实验中观察到的现象 | 可由计算研究的分子问题 | 预期产出 |
| --- | --- | --- |
| 联合处理是否强于单独处理 | 臭氧及其活性氧相关物种在不同水体微环境中的反应路径与相对势垒 | 反应路径、相对反应性排序 |
| 水样组成改变后消毒效果为何不同 | Cl⁻、HCO₃⁻、铵态氮和简化溶解有机质等对活性物种的竞争反应或猝灭作用 | 水体基质效应的分子解释 |

## 边界与方法选择

- DFT 适合计算分子结构、相对能量、反应路径、势垒和溶剂化影响；它不能直接预测整个养殖系统的菌落数、鱼体应激或消毒率。
- 微纳米气泡的尺寸分布、上浮、流场和传质属于介观/宏观问题；当前DFT先建立分子参考与目标物反应模型。界面组成和实验问题明确后，再论证界面计算。
- 常规基态 DFT 不能单独完整描述紫外光激发。现阶段将紫外视为形成或改变活性物种的实验边界条件，优先比较其下游反应；若要直接研究激发态，需另行确定 TD-DFT/光化学计算路线。
- 方案中的生物安全、臭氧和紫外操作要求只适用于实验实施；本目录不包含病原培养或养殖实验操作。

## 按已批准计划推进

1. **臭氧水合基线**：固定方法、溶剂处理和验收标准，记录电子态及适用范围。
2. **目标物反应模型**：当前推进NH₃＋O₃接触构型，后续选择中间体、产物及活性氧支路。
3. **反应路径与能垒**：对优先路径开展过渡态、频率和IRC等连接验证。
4. **紫外与界面扩展**：根据实验需要分别论证激发态或气液界面模型。

与实验对照贯穿各阶段；生物替代物属于后续可能分支，并非当前自动执行任务。具体进度和未完成项见[总进度](PROJECT_STATUS.md)。

## 记录规范

每个计算都应保留：模型组成、结构来源、溶剂模型、泛函/基组、电子态、电荷、任务类型、服务任务编号、收敛状态及结果解释。使用[计算记录模板](templates/calculation_record.md)建档，避免不同水体或不同批次的结果混淆。

所有计算文件与 DFT 平台源码必须严格隔离；目录归属、允许修改范围和平台缺陷修复流程见[项目工作区与 DFT 平台边界](notes/workspace_governance.md)。

当前气相计算已启动；水体类型、pH、UV波长等实验输入仍需补齐，以决定后续水相与协同机制模型。每批都应说明其与原计划的关系，并同步更新[研究方向与当前进度](PROJECT_STATUS.md)。
