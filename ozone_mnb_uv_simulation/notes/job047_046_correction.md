# JOB-047 对 JOB-046 的零求值补正

**日期**：2026-09-09 · **性质**：表述修正，无新求值 · 046 的 8 次求值数据不变。

## 1. "24.9% 解释占比"改为绝对量级比

原表述"Δk_grid 解释原差额的 24.9%"隐含"贡献可从差额中线性扣除"的读法，**不成立**——带符号的两个差额并不支持这种减法。修正为绝对量级比：

- |Δk_grid| / |k_H − k_on| = 3.459×10⁻⁵ / 1.389×10⁻⁴ ≈ **0.25（绝对量级比，不称"消除差额"）**；
- 方向性事实：Δk_grid < 0（网格响应使 FD 曲率更负，与 k_H 同号方向），但 k_off 比 k_on **更远离** k_H。

## 2. 保留两个带符号差额，删除"剩余 1.04×10⁻⁴"

原报告"剩余 ~1.04×10⁻⁴（75.1%）未解释"是错误减法（用 |k_H−k_on| 减 |Δk_grid|，隐含了不成立的线性扣除假设）。**修正：保留两个带符号差额本身，不做中间减法**：

- 原差额：k_H − k_on = **−1.3886×10⁻⁴** Eh/Bohr²；
- 关响应差额：k_H − k_off = **−1.7345×10⁻⁴** Eh/Bohr²。

差额的完整刻画就是这两个数 + Δk_grid = −3.4590×10⁻⁵。"未解释量"不做单一数字压缩。

## 3. D2 结论限定

"解析 d2_grad 曲率与 043 D2 FD Hessian 一致至 4.6×10⁻¹¹"的结论**仅适用于当前几何（041 attempt 5 ± 0.01 Bohr）、当前方向 q、当前步长 h=0.01 Bohr**，不外推为"D2 Hessian 已验证"的一般结论。

## 4. RSH 表述

ωB97xd 为 range-separated hybrid（实测 is_rsh=True）、PySCF 解析 Hessian 的 RSH 二阶导可能有方法学局限——**仅列待定假说（H3）**，本批及 046 均未提供支持或反对的证据。

## 5. 原始未对称化矩阵缺失（H2）

该缺失限制**逐元素审查能力**。对称化不改变固定实方向的二次型（实 q 下 qᵀ[(H+Hᵀ)/2]q = qᵀHq 恒成立），因此矩阵缺失/对称化**不能作为**固定方向二次型差异（k_H vs FD）的独立解释——H2 仅说明"无法进一步逐元素排查"，不是差异来源的候选解释。
