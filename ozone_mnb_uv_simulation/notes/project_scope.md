# 与预实验方案的对应关系

## 当前范围更新（2026-09-09）

当前有效阶段与成果状态见[研究方向与当前进度](../PROJECT_STATUS.md)。导师已批准四阶段总体路线，当前已进入NH₃＋O₃气相接触构型研究；水相基线验收仍有开放项。下文JOB-015的“具体化学组分尚未确定”为当时记录，不再表示第二阶段尚未启动。

氨氮相关NH₃模型是当前执行分支；具体实验水质、pH、UV波长和最终课题范围仍须结合用户实验确认。病毒、其他污染物、激发态与界面模型不是已自动启动的计算内容。

本工作区以“臭氧/紫外协同处理养殖水体消毒效果预实验方案”为研究背景，但不复制或执行其中的实验操作内容。

可用于建模的变量包括：处理组别（对照、臭氧、紫外、联合处理）、处理时间、臭氧处理强度、紫外功率、循环流量、污染暴露时间和水体成分。计算优先研究其中能够在分子尺度明确表示的因素：臭氧及活性氧相关物种、溶液离子/有机物、气液界面和生物替代物。

实验数据的主要对照指标可包括水体或鱼体表面细菌总数、去除率、对数削减值、残余臭氧、ORP、pH、DO 和温度。计算结果只用于提出或支持机理解释，应与这些观测数据共同判断。
