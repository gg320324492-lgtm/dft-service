# 第二阶段首批任务草案：铵态氮氧化 · 首批研究问题（**草案 v2——021 批收窄；未批准、未执行**）

**编制：JOB-2026-0906-020 · 2026-09-07 · 供总指挥与老师审议**

## 1. 科学问题（唯一）

**在水相中，·OH 引发的铵氧化初始基元步（·OH + NH₃ → NH₂· + H₂O 抽氢通道）与臭氧直接反应（O₃ + NH₃）相比，其反应自由能与能垒差异的分子来源是什么？NH₃/NH₄⁺ 形态（pH）如何改变这一竞争？**

依据：文献已定标宏观速率（O₃ 直氧 k≈4.6–5 M⁻¹s⁻¹ 慢、pH>8 显著；·OH k≈6.15×10⁷ M⁻¹s⁻¹，Cai 等/ Hoigné–Bader），但**基元步层面的分子解释缺失**（未检索到 DFT 文献——研究空白）。此问题直接对应"臭氧+紫外协同"主题（·OH 由 UV/O₃ 体系产生）。

## 2. 所需模型与对照

| 体系 | 说明 |
|---|---|
| M1 | NH₃(aq) + ·OH → NH₂·(aq) + H₂O(aq)——抽氢过渡态搜索 |
| M2 | NH₄⁺(aq) + ·OH（对照：质子化形态为何不反应/能垒高） |
| M3 | NH₃(aq) + O₃（直接加成/抽氢候选过渡态；对照"慢"的分子根源） |
| 对照组 | 复用第一阶段已验收的 O₃(g/SMD) 与 H₂O(g/SMD) 基线作为参考物种能量锚点（不重算，兼容性核验后引用） |

**明确不做**：完整 NO₃⁻/N₂ 产物链（后续批）、界面/微纳米气泡模型、病毒相关体系、动力学建模。

# 【021 批收窄】最小研究问题与分阶段任务组成（取代上方 §1–§7 的宽口径设计）

## A. 收窄后的最小研究问题

> **复现并扩展气相 NH₃+O₃ 反应的通道图像，再扩展到水相。**
- **具体反应物**：NH₃ + O₃（气相，基准复现）；NH₃(aq) + O₃ 与 NH₃(aq) + ·OH（水相扩展，第二阶段）。
- **比较变量**：通道归属（对照 S13 的 P1–P6 定性结论）与相对通道能量排序（**非数值复现**——方法不同）；水相扩展后比较溶剂效应与 NH₃/NH₄⁺ 形态差异。
- **已有文献基准**：S13 气相结论（无垒加合物、C1/C2、六通道、P1(2)/P4 最可能；依据仅摘要）；S1/S2 宏观速率常数（条件限定）。
- **预期计算输出**：项目方法（wb97xd+D2）下的气相通道相对能量排序表；水相 vs 气相的通道稳定性变化表（第二阶段）。

## B. 首次基准复现 与 水环境扩展 —— 严格分开

**第一小批（基准复现，气相；水体条件确定前即可准备）**
- 内容：NH₃+O₃ 单重态 PES 上，定位加合物与主通道（聚焦 P1/P4，不铺开全部六通道的完整变速率计算）；
- 方法：项目现行 wb97xd+−D2 路径（闭壳层！——基准复现无需开壳层，风险最低）；
- 预算组成（暂列，**不含** 60–90 旧数字）：加合物/络合物优化 ~3–4 点 + 主通道过渡态与产物 ~6–8 点 + 交接基线复核 ~2 点 ≈ **12–15 求值**（批准时定案）；
- 输出：与 S13 定性对照表（通道存在性/排序；不宣称数值一致——方法不同）。

**第二小批（水相扩展；依赖水体类型/pH 决策）**
- 内容：主通道的 SMD 水相扩展 + NH₄⁺ 对照 + ·OH 抽氢通道（引入开壳层）；

- 前置验证：开壳层 <S²>、自由基 SMD 适用性、N/H 体系 D2 一致性（020 草案 §4 保留）。
