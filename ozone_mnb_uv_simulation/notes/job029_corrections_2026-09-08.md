## 3. 029 几何重建的原则（见 `protocols/c1_scan_geometry_v2.py`）

- 全局轴无关定义：C = 中心氧；M = 两端氧中点；**u = (M−C)/\|M−C\|（指向端氧侧）**；**N = M + s·u，s > 0**；
- 目标 d = 两 N—端氧距离的**平均值**；端氧微不对称**不做对称公式套用**，以 1D 数值求根（Brent）求 s；
- NH₃ 作为**完整刚体**放置：N 落在 N 目标位，H 质心位于 N 的 +u 侧（H 质心→N 指向 O₃）——**明确为初猜几何约定，不是孤对电子密度计算结果**；
- 中心氧识别 = 已验证原子映射 + 距离关系复核（修复"对角线 1e9 + 行最大"在特定排序下的恒定结果问题）；
- 所有旋转矩阵断言 RᵀR = I、det(R) = +1；反平行轴的 180° 旋转用 Rodrigues 公式绕垂直轴实现，**不用 −I 代替**；
- 单体内部几何不改；不以调整键长/键角满足文献图值。
