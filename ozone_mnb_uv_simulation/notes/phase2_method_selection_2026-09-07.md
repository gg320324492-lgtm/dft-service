# 方法选择说明（JOB-2026-0906-023 · 2026-09-07）

## 1. 首批最小单元推荐：**NH₃+O₃ 气相基准对照**（而非 NH₃+OH）

| 准则 | NH₃+O₃ 气相基准 | NH₃+OH（·OH 抽氢） |
|---|---|---|
| 文献基准 | **S13 全文在手**（结构图示、Table 1–4、10 TS、能垒、T1）——可逐点对照 | Corchado 1993（4 页简读）、Vahedpour 2017、JPCA 2017 高级别速率——**能垒数值未提取**，需补读 |
| 电子态 | 反应物/加合物段**闭壳层可用**（附 <S²>/稳定性检查）；P4/P5 产物通道亦闭壳层 | **天生开壳层**（·OH D、NH₂ D）——方法验证必须先行 |
| 与既有基线衔接 | 直接复用 O₃、H₂O 参考谱（注意口径） | 需 HO₂/NH₂OO· 等更多开壳层物种 |
| 成本 | 低（最小单元 ≤2 作业 ≤13 求值） | 中 |
| **结论** | **推荐为首批**（022 草案的 NH₃ 基线+加合物试探即其前半） | 第二批（待开壳层验证与文献精读） |

**NH₂OH+O₃ 暂作后续候选**：NH₂OH 文献均为外加试剂体系（非 NH₃ 氧化中间体证明）；是否纳入取决于首批结果与 NH₂OO·→NH₂OH 证据。

## 2. "原文方法复现" vs "本项目方法对照"

- **原文方法**：Gaussian 03；B3LYP/6-311++G(3df,3pd) 几何；CCSD(T) 与 G3B3 单点；IRC；CP/BSSE；AIM2000；SSUMES/GPOP 速率。
- **本项目**：PySCF 2.14.0；wb97xd(libxc)+项目−D2 全导数 / def2-TZVP / L8 / grid_response / SCF 1e-12,1e-9；SMD(water) 可选。
- **结论**：方法不同 → 首批为**项目方法对照**（通道存在性/相对排序的定性比较，S13 Table 1 为参考图景），**不得称复现**。若总指挥要求真正复现，PySCF **具备** B3LYP/6-311++G(3df,3pd) 与 CCSD(T) 能力（工具支持存在），可作为另行批准的复现批——**不与对照批混算**。

## 4. 电子态方案（整体 vs 片段）

- 反应物/加合物/闭壳层通道（P4/P5）：整体单重态 + **RKS 起步 + <S²>/稳定性检查**（O₃ 多参考风险，S13 T1=0.0346 佐证）。
- 开壳层通道（P1/P2/P3/P6）：**UKS + 自旋态扫描**（单重耦合 vs 三重态），片段自旋分别判定（如 P1 = 两个 D 片段）；禁止由整体单重态直接推定 RKS。
- S13 的 T1 表作为**多参考风险地图**使用（TS6 0.1048、P6 0.0601 等为高风险点）。

## 5. 显式水政策

- 首批（气相基准对照）**不用显式水**；
- 水相扩展如需显式水：其表示的物理过程（NH₃/NH₄⁺ 氢键对形态与能垒的影响）→ 构型选择 = NH₃/NH₄⁺ 第一水合壳层构型扫描 → 规模检验 = n=1,2,4,6 收敛对照（**不预设 3–6 个**，由收敛性决定）。

## 6. 基线兼容性

- O₃/H₂O 基线（`models/00_baseline/`）为 grid5/SCF 1e-11/**D2 单点口径**；本批对照为 L8/1e-12/**D2 全导数**——**几何可复用，能量不可混表**；如需能量参考须按本批配置重算（计入预算）。
- 受限电子能结果（018）与水相诊断结果**不进入**气相基准对照的数值比较。
